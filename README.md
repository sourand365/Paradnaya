# Парадная

Android-приложение с 3D-картой домов, парадными, этажами и карточками квартир.

## Технологии
- Flutter
- MapLibre
- OpenStreetMap data
- OpenFreeMap Liberty style

## Первая версия
- Стартовая камера на Одессу.
- Наклон и вращение карты.
- 3D-стиль Liberty.
- Поле поиска-заготовка.

Поиск, собственные метки парадных, этажи, квартиры, отзывы и инструкции будут добавлены следующими этапами.

## Запуск локально
Требуется Flutter SDK.

```bash
flutter create --platforms=android --project-name=paradnaya .
flutter pub get
flutter run
```

## Сборка APK
GitHub Actions автоматически создаёт Android APK при push в `main`.

Картографические данные OpenStreetMap и стиль OpenFreeMap предоставляются отдельно от приложения. Перед публичным запуском необходимо соблюдать их условия использования и атрибуцию, а при росте нагрузки выбрать подходящий тариф или собственный хостинг тайлов.
